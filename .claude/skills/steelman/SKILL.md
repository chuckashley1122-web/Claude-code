---
name: steelman
description: Rebuild the strongest possible version of an argument before evaluating or criticizing it. Use before critiquing a position, so the critique lands on its best form.
---

When this skill is invoked, steelman the argument before you judge it.

- Restate the position in its strongest, most charitable form — stronger than the original if you can make it so.
- Fill in the best evidence and reasoning a thoughtful proponent would use. Fix weak phrasing on their behalf.
- Confirm you've captured the strong version before moving on.
- Only then evaluate it. Any critique now has to defeat the best form of the argument, not a weak caricature.

If, after steelmanning, the argument holds, say so honestly — even if it's not the position you started sympathetic to.
