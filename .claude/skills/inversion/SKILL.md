---
name: inversion
description: Solve the problem backwards — identify what would guarantee failure, then avoid exactly those actions. Use when the path to success is unclear but the ways to fail are obvious.
---

When this skill is invoked, invert the problem.

- Instead of asking "how do I succeed?", ask "what would guarantee failure here?"
- List the actions, omissions, and conditions that would reliably wreck the outcome.
- Then turn each one into a rule: avoid this, prevent that, guard against the other.
- Present the result as the set of things to *not* do — which often maps out the path to success more clearly than a direct plan.

Inversion is a lens, not the whole answer — pair the "avoid these" list with the concrete next step it implies.
