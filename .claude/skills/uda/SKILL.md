---
name: uda
description: Run a rigorous, military-style root-cause analysis (Unrestricted Deep Analysis), breaking the problem down from every angle to find the real cause. Use for debugging, incidents, and failures.
---

When this skill is invoked, run a disciplined root-cause analysis. Break the problem down from every angle rather than jumping to the first plausible cause.

Work through it methodically:

1. **Define the problem precisely.** What exactly is failing, where, and how do we know?
2. **Gather evidence.** Symptoms, logs, timing, what changed, what's consistent vs. intermittent.
3. **Decompose.** Break the system into components and attack each: could this layer be the cause? Rule things in and out with reasoning.
4. **Trace causal chains.** Ask "why" repeatedly until you reach a root cause, not a symptom.
5. **Distinguish root cause from contributing factors.** Name both.
6. **Recommend a fix and a verification** that would confirm the root cause is correct.

Show your reasoning at each step. Don't stop at the first thing that looks wrong.
