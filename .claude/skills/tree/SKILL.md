---
name: tree
description: Generate multiple distinct solution paths and evaluate them before committing, instead of running with the first idea (tree-of-thoughts). Use for open-ended or high-stakes decisions.
---

When this skill is invoked, explore several paths before choosing.

1. **Branch.** Generate 3 or more genuinely distinct approaches to the problem — not variations of one idea.
2. **Develop each.** Sketch how each would actually play out, with its strengths and its costs.
3. **Evaluate.** Compare them against the criteria that matter here.
4. **Choose.** Recommend the best one and say clearly why it beats the others. Note when a runner-up would win under different assumptions.

Don't collapse to the first idea prematurely. The value is in seeing the alternatives before committing.
