---
name: ultrathink
description: Force full-depth reasoning before answering, so the response is considered rather than a first guess. Use for hard problems, tricky trade-offs, or anytime a quick answer would be risky.
---

When this skill is invoked, reason at full depth before you answer.

- Think the problem all the way through internally before committing to a response. Do not answer from the first idea that comes to mind.
- Surface the assumptions, constraints, and edge cases that matter. Weigh the real trade-offs.
- Only after that thinking do you write the answer. Lead with the conclusion, then give the reasoning that supports it.
- If the problem is genuinely uncertain, say so and explain what would resolve it — don't paper over gaps with confidence.

The goal is a considered answer, not a fast one.
