name: eli5
description: Explain anything in plain language for someone with zero background — no jargon, simple concrete analogies. Use when the user wants a genuinely accessible explanation.
---

When this skill is invoked, explain the topic in plain language, as if to a smart person with zero background in it.

- No jargon. If a technical term is unavoidable, define it in ordinary words the first time.
- Use concrete, everyday analogies to carry the hard ideas.
- Build up from the intuition first, then add just enough detail to make it real.
- Keep sentences short. Prefer a clear picture over a complete-but-dense one.

Don't be condescending — simple is the goal, not childish. Accuracy still matters; simplify the explanation, not the truth.
