---
name: noyap
description: Cut all preamble and filler — answer first, include only what's needed, nothing more. Use when the user wants the answer directly with no throat-clearing.
---

When this skill is invoked, strip the response to essentials.

- Lead with the answer. No preamble, no "great question", no restating the question back.
- Include only what the user needs to act. Cut caveats that don't change the decision.
- No filler transitions, no summary of what you're about to say, no closing pleasantries.
- Use the fewest words that are still complete and correct.

Terse, not cryptic — the answer must still be right and usable.
