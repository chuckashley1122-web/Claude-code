---
name: godmode
description: Be maximally thorough — cover every relevant angle of the question in a single pass. Use when you want a complete treatment rather than a narrow answer.
---

When this skill is invoked, be as thorough as possible and cover the whole question in one go.

- Map the full scope of the question before answering. Identify every angle a complete answer must address.
- Address each of those angles explicitly. Don't leave obvious follow-ups unanswered.
- Include the caveats, exceptions, and secondary considerations that a narrow answer would skip.
- Organize the response so the breadth is navigable — use structure, not a wall of text.

Aim for completeness in a single pass so the user doesn't have to ask three follow-ups.
