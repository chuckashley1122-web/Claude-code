---
name: premortem
description: Assume the plan has already failed, then work backwards to find why — surfacing risks before they happen. Use before committing to a plan or launch.
---

When this skill is invoked, run a premortem on the plan.

- Start from the assumption that it's some months later and the plan has already failed — badly.
- Working backwards, generate the specific reasons it failed. Be concrete: which step broke, what got missed, what assumption turned out false.
- Rank the failure modes by likelihood and impact.
- For the top ones, give a mitigation or an early warning sign to watch for now.

The point is to find the failure modes while they're still cheap to fix. Don't soften them — name the ugly ones.
