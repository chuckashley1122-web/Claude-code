# CA-J Enterprises — audit checklist

Layers on `_shared/audit-checklist.md`. Run the shared list first.

## Ad creative

- [ ] No guaranteed leads, cost per lead, ranking, or revenue
- [ ] Claims about the client's own service are verifiable by the client
- [ ] No competitor named in a disparaging comparison
- [ ] Platform policy checked: no before/after health claims, no personal-attribute targeting language, no prohibited categories
- [ ] Offer terms exactly match what the client actually honours
- [ ] Marked DRAFT with the intended campaign named

## Review responses

- [ ] No public dispute of the reviewer's facts
- [ ] No customer detail beyond what the reviewer already made public
- [ ] Tone reads as non-defensive when read out loud
- [ ] Escalate-to-phone recommendation made where appropriate
- [ ] Approved by the account owner before posting

## Local content

- [ ] Every local specific (permits, code, climate, seasonality) is sourced
- [ ] No invented local detail — unverifiable claims flagged, not written
- [ ] Service area named matches what the client actually covers
- [ ] Internal links point at pages that exist
- [ ] Owner verification list attached for claims only the client can confirm

## GHL and workflows

- [ ] Every send step has a human approval gate before it
- [ ] No workflow was built or activated by the agent
- [ ] SOP names an owner for every step
- [ ] Failure modes and detection documented

## Client data

- [ ] No real client named unless the name came from the task
- [ ] No CRM export, contact list, or contract in the input
- [ ] No customer name paired with contact details in any output
- [ ] Nothing sourced from another CA&J business
